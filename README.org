To build the site, run:

#+begin_src shell
clojure -M:build
#+end_src

This statically generates the HTML files and compiles the front-end files into =site=.

For live development you can serve the build of the site interactively. Navigate to a Clojure file, enter a REPL via =cider-jack-in-clj= and run this:

#+begin_src clojure
user> (serve!)
#+end_src
